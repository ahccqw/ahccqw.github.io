第二步：在 GitHub 创建仓库

  1. 登录 GitHub，新建一个仓库（Repository）。
  2. 仓库名称必须是：你的用户名.github.io（例如 ahccqw.github.io）。
  3. 权限设置为 Public（公开），不要勾选初始化 README。

第六步：开启 GitHub Pages 服务

  1. 进入你 GitHub 上的 你的用户名.github.io 仓库页面。
  2. 点击顶部的 Settings（注意是仓库的 Settings，不是账号的）。
  3. 左侧菜单找到 Pages。
  4. 在 Build and deployment 下，Source 选择 Deploy from a branch。
  5. Branch 选择 main（或 master），文件夹选 / (root)，点击 Save。
  6. 等待 1-2 分钟，刷新页面，看到绿色的成功提示，即可访问 https://你的用户名.github.io。
